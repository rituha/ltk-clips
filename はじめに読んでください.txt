LTK Finale クリップアルバム　はじめに読んでください
==================================================

LTK Season: Finale の Twitch クリップを、チーム・選手と紐づけて集め、
選んだチームや選手のクリップをランダムに（1周するまで重複なしで）流すWebサイトです。
大御所にゅん子さんが大会を振り返るために作りました。


■ 入っているファイル（すべてメモ帳で中身を読めます）
--------------------------------------------------
  index.html ……… サイト本体（画面と動き）
  schedule.html … 日程ページ（カレンダーから日ごとにクリップを見る）
  calendar.js …… 10月・11月のカレンダーと大会の予定（両方のページで共用）
  admin.html …… 管理ページ（合言葉つきURLで開いたときだけ、クリップの編集・削除ができる）
  config.js ……… データベース（Firebase）の接続先を書くファイル
  firestore.rules … データベースの書き込みルール（Firebase に貼り付ける）
  はじめに読んでください.txt … このファイル


■ このサイトがすること
--------------------------------------------------
  ・Twitch クリップのリンクを貼って選手を選ぶと、チーム・選手・クリップを紐づけて保存する
  ・同じクリップのリンクが貼られたら、新しく作らず1つにまとめる
    （書き方が違うリンクでも、中のクリップIDで同じものと判断します。
      別の選手が選ばれていたら、その選手だけ追加します）
  ・選んだチーム（複数可）または選手（複数可）のクリップを、シャッフルして重複なしで再生する
  ・クリップは Twitch 公式の埋め込みプレイヤーで再生する

■ このサイトがしないこと
--------------------------------------------------
  ・動画をダウンロード・保存・再アップロードしない（保存するのはリンクだけ）
  ・名前・メールアドレスなどの個人情報は集めない。ログイン機能もない
  ・見に来た人のパソコンに何もインストールしない
  ・通信するのは次の3か所だけ
      Firebase（Google）……… 登録されたクリップの保存と読み込み
      Twitch ……………………… クリップの再生
      GitHub Pages ………… このサイト自体の置き場所


■ まずは手元で試す（お試しモード）
--------------------------------------------------
  index.html をダブルクリックで開くと「お試しモード」で動きます。
  ・登録したクリップはそのブラウザの中にだけ保存され、どこにも送信しません
  ・この状態だと Twitch の仕組み上、サイト内での再生はできません
    （「Twitchで開く」で別タブ再生になります）。
    サイト内で再生されるのは、下の手順でWebに公開したあとです。


■ みんなで使えるように公開する手順
--------------------------------------------------
※ どれも無料プランで足ります。クレジットカードの登録は不要です。
※ アカウント作成やログインは、ご自身で行ってください。

【手順1】Firebase（データ保存先）を作る
  1. https://console.firebase.google.com/ を開き、Google アカウントでログイン
  2. 「プロジェクトを作成」→ 名前は例えば ltk-clips
     （Google アナリティクスは「オフ」で大丈夫です）
  3. 左メニュー「構築」→「Firestore Database」→「データベースを作成」
       ロケーション：asia-northeast1（東京）
       モード：「本番環境モード」

【手順2】書き込みルールを設定する
  1. Firestore Database の「ルール」タブを開く
  2. 最初から入っている文字を全部消して、firestore.rules の中身を丸ごと貼り付け
  3. 「公開」を押す

【手順3】config.js に接続先を書く
  1. Firebase の左上の歯車 →「プロジェクトの設定」→ 下の「マイアプリ」で「</>」（ウェブ）を押す
  2. アプリ名を入れて登録（「Firebase Hosting も設定する」はチェック不要）
  3. 表示された firebaseConfig = { … } の { } の中身をコピー
  4. config.js をメモ帳で開き、window.LTK_FIREBASE_CONFIG = { } の中に貼り付けて保存
     ※ この値はパスワードではありません。Firebase の設計上、Webサイトに載せて
        公開される前提の値です。データの安全は手順2のルールで守っています。

【手順4】GitHub Pages でWebに公開する
  1. https://github.com/ でアカウントを作成・ログイン
  2. 右上「＋」→「New repository」→ 名前は例えば ltk-clips、「Public」を選んで作成
  3. 「uploading an existing file」から index.html と config.js をドラッグして「Commit changes」
  4. リポジトリの「Settings」→ 左の「Pages」→ Branch を「main」「/(root)」にして「Save」
  5. 数分後、 https://（GitHubのユーザー名）.github.io/ltk-clips/ で開けるようになります
     このURLをにゅん子さんや登録してくれる人に共有してください。


■ 知っておいてほしいこと（リスク）
--------------------------------------------------
  ・URLを知っている人なら誰でも登録できます。
    ルールで「Twitch クリップのIDの形」「決められた60人の選手」しか登録できないようにし、
    登録済みのものを消したり書き換えたりはできないようにしていますが、
    関係ないクリップを登録されることはあり得ます。
  ・GitHub の Public リポジトリなので、サイトのファイル（config.js 含む）は誰でも見られます。
    個人情報やパスワードは入っていません。
  ・無料プランには1日の読み込み回数の上限があります（約5万回）。
    超えた日はクリップの読み込みが止まり、翌日に戻ります。勝手に料金がかかることはありません。
  ・選手の名簿は 2026/10/07 時点の公開情報です。変更があれば index.html と firestore.rules の両方を直します。


■ まちがった登録を直す・消すには（管理者）
--------------------------------------------------
  管理用URL（admin.html#合言葉）を開いて、クリップの「編集」から直すか削除します。
  管理用URLは、手元の「管理用URL（人に見せない）.txt」に書いてあります。
  このファイルと合言葉は GitHub に載せないでください。
  （Firebase の「Firestore Database」→「データ」→ clips から直接消すこともできます）
  ※ 管理ページは Firebase の「匿名ログイン」を使います。名前やメールは集めません。


■ 完全な消し方
--------------------------------------------------
  1. GitHub：リポジトリの「Settings」→ 一番下「Delete this repository」
     → サイトが見られなくなります
  2. Firebase：「プロジェクトの設定」→ 一番下「プロジェクトを削除」
     → 登録されたクリップのデータがすべて消えます
  3. 手元のフォルダ（このファイルが入っているフォルダ）をごみ箱へ
  お試しモードで使ったブラウザのデータは、ブラウザの「閲覧データの削除」で
  このファイルを開いたサイトのデータを消すと消えます。
